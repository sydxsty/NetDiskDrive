# Third-party components

- **WinSpd:** https://github.com/winfsp/winspd. C# binding source pinned to `55c53bc454afbbba38bd1692f52beb77ed59142f`; native runtime/installer from `v1.0B1`, `winspd-1.0.20357.msi`. Upstream GPLv3 with its stated exceptions/commercial licensing; full license and binding modification notes are under `app/ThirdParty/WinSpd/` in the source package. The installer SHA256 is `f1157eef805dcbec78a477f2b4ee5abc0049c8a9329444e5d18cab01d3604265`. The official driver was installed, with user authorization, for the documented Windows integration tests. This does not establish compatibility with every Windows security configuration.
- **Rust dependencies:** exact versions and checksums are in `engine/Cargo.lock`. RustCrypto SHA-256 provides local checksums; fs2 provides the exclusive container lock. Local Argon2 and XChaCha20-Poly1305 dependencies have been removed. Cloud PBKDF2, AES-256-GCM and HMAC use the .NET cryptography implementation. The current engine stores volume state in a single file. Obsolete engines and their rusqlite/SQLite dependency have been removed. Individual upstream licenses apply.
- **.NET 8 / Windows Forms:** Microsoft framework. This portable build requires the installed .NET 8 Desktop Runtime. Windows Forms hosts the native window, tray and WebView2 control; all product management pages use WebView2. The framework runtime is not bundled.
- **Microsoft WebView2:** NuGet SDK `Microsoft.Web.WebView2` version `1.0.4258.31`, including its managed assemblies and x64 loader, under Microsoft's package license (copy: `docs/WEBVIEW2-LICENSE.txt`). The installed WebView2 Runtime is required and is not bundled. License: https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31/License . SDK/runtime use remains subject to Microsoft's terms.
- **ZstdSharp.Port:** NuGet `0.8.8`, managed zstd implementation under MIT. Fixed encoder profile and exact source revision are documented in `docs/ZSTD-PROVENANCE.md`; the upstream license is included as `docs/ZSTD-LICENSE.txt`.
- **Baidu private protocol references:** the client is independently implemented; no third-party cloud client is bundled. Request behavior was checked against `komorebiCarry/BaiduPCS-Rust` commit `427c5c38d8589b91c3a5fee09e5c9c246ad7c27e` and `PeterDing/BaiduPCS-Py` commit `e81e9b65c4b35fc8f7f2993a81e25e0bc24608db`. The first repository has Apache-2.0 LICENSE text and additional commercial restriction text in its README; it is used as a protocol reference, not imported source. The second repository states MIT. Exact source links and compatibility limits are in `cloud/OverlayDisk.Cloud.Baidu/README.md` (release copy: `docs/BAIDU-BACKEND.md`).
